# Glyph artwork

The bundled Glyph portrait, poses, observatory scene and derived icon are original project artwork attributed to **Mëngøh Labs**. The scene is an image-generated adaptation using the project's character references. Artwork is bundled locally; displaying it does not contact an image service.

Page artwork preserves its proportions and is static; the build includes selected resources rather than the private design history.
